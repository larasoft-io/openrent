DXB-009 · Rent capRule definition
DXB-009LawRenewalsHard block

Rent increases capped by the Smart Rental Index

On renewal, rent can only rise if it is more than 10% below the index rent for your building: up to 5% (11–20% below), 10% (21–30%), 15% (31–40%) or 20% (more than 40% below).

Decree 43/2013 · DLD Smart Rental Index (2025)
Public rulebook entry

Rule logic

Read-only · generated from the ruleset
rule DXB-009 "Rent increase cap"
  applies_to   renewal
  jurisdiction dubai
  source       "Decree 43/2013" + smart_rental_index

  inputs       current_rent, proposed_rent, index_rent(unit)
  gap          = (index_rent - current_rent) / index_rent

  max_increase = 0%   when gap <= 10%
                 5%   when gap <= 20%
                 10%  when gap <= 30%
                 15%  when gap <= 40%
                 20%  otherwise

  requires     DXB-014            # 90 days' notice, else 0%
  enforce      BLOCK when proposed_rent >
               current_rent * (1 + max_increase)
  on_missing   index_rent -> manager_review
  explain      tenant, landlord   # EN + AR templates
